# 前期市场调研范围（内部）

**这不是网站内容。** 这是我们两个人之间的工作笔记：决定前期先调研哪些区域、
哪些问法、用什么口径。它不应该出现在客户看到的页面上——把它放到站内，
就成了"自说自话"，客户不关心你怎么给自己分梯队。

**状态：** 内部工作文件 · 2026-10-24

---

## 1. 调研范围（按优先级）

### 第一批：海湾、东南亚、东亚、大洋洲

- 理由：建设与文旅投资活跃、以英语签约、对定制化（非目录商品）的接受度高。
- 国家：阿联酋、沙特阿拉伯、卡塔尔、科威特、阿曼、巴林、新加坡、马来西亚、
  泰国、越南、印度尼西亚、日本、韩国、澳大利亚、新西兰。
- 问法侧重：度假村与酒店的总包与分期、主题乐园与文旅 IP 的落地、
  公共空间与景观的年度预算、"找谁做才靠谱"。

### 第二批：东欧、中亚、非洲

- 理由：俄语与阿语采购环境、物流链更长，更需要能守住整份任务书的伙伴。
- 国家：俄罗斯、波兰、罗马尼亚、捷克、爱沙尼亚、拉脱维亚、立陶宛、乌克兰、
  哈萨克斯坦、乌兹别克斯坦、吉尔吉斯斯坦、南非、毛里求斯、塞舌尔。
- 问法侧重：谁来当总包、认证怎么做、跨境运输与清关、付款方式与质保。

### 第三批：低门槛高投资市场

- 理由：按"人均 GDP > 5,000 美元"硬筛，非洲只剩南非等极少数——这是对
  筛选标准的一次诚实修正。东非（肯尼亚等）虽然人均低于门槛，但旅游与公共
  空间投资额可观。
- 处理方式：与主市场分开统计，不混算指标，但服务条件相同。
- 国家：肯尼亚、坦桑尼亚、卢旺达、加纳、尼日利亚。

## 2. 调研什么

1. **需求簇**：客户真正在决策的事（范围界定、伙伴选择、成本结构、合规与
   标准、时间表、招标与合同），而不是产品词。
2. **买家原话**：自动补全里出现的真实问法，作为术语表的来源。
3. **胜出页面形态**：某一类问题上，什么样的页面形态被引用最多——这决定我们
   写什么、怎么写。
4. **可争夺词区**：哪些词被设备商和经销商占据（我们不参与），哪些是
   决策类与规格类问题（我们参与）。

## 3. 口径（已经定下来的）

- 我们是服务型公司，不是设备制造商，不拥有工厂。写内容、做说明时，
  "服务型公司 / 设计 / 供应链 / 交付"是正向表述，"制造商 / 工厂"只出现在
  否定句里（"我们不是"、"我们不拥有"）。
- 内容里出现的每一个数字都要有来源和取样日期；不知道的事实留空。
- 客户名、项目名、认证、价格区间一律不编。

## 4. 为什么这些内容不上站

- 分梯队、按人均 GDP 划线，是我们的内部分析，客户读了只会困惑：
  "我是不是被归到第三档了？"
- 站上真正需要的是"能不能合作"的判断依据——总部在哪、做过什么类型、
  怎么交付、交付什么形态。这些在事实页与交付模式里已经说清。
- 调研范围会随季度复盘变化，放进站内等于每季度都要改一遍公开页面，
  而且改动看不出理由。
