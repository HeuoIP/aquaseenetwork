# 文案规则（内部工作文件）

**这不是网站内容，是我们的写作纪律。** 2026-10-24 起执行。

---

## 1. 最高原则：站在买家那边写

每一段话，先问一句：**买家此刻在担心什么？** 然后从他的处境开写，再给我们的答案。

| 不要这样写 | 这样写 |
| --- | --- |
| AQUASEE 为文旅、公共空间与儿童游乐项目提供三项能力 | 你手里有一个想法、一个场地和一个日期。你需要的是有人把它从"要不要做"一路带到"建好了、装上了、能用了" |
| 我们刻意不做工厂，也不以工厂的身份出现 | 我们不是工厂，也不装成工厂 |
| AQUASEE 建立在这样的假设上：好的结果来自清晰的预期 | 好的结果来自清晰的预期、诚实的数字，以及少数几个你能追责的关系 |

**判断标准**：把公司名遮住，这段话读起来还像不像在对一个买家说话？不像，就重写。

## 2. 自说自话的三种典型

1. **讲我们的体系，而不是买家的处境**——"我们提供三项相互衔接的能力"是体系，"你不用担心设计和生产对不上"才是处境。
2. **讲我们的方法，而不是买家的风险**——"我们采用模块化设计"是方法，"十年后还修得起"是风险。
3. **把内部分析搬上站**——例如给市场分梯队、注明人均 GDP 门槛。客户读了只会困惑："我是不是被归到第三档了？"这类内容属于工作笔记，不属于网站（见 `docs/market-research.md`）。

## 3. 不要反复否定，要论证优势

"我们不是工厂"这句话，说一次是事实，说三次就变成了口号——而且把注意力引到了客户本来没在想的对比上。正确做法是**把对比说成优势**：

| 不要这样写 | 这样写 |
| --- | --- |
| 我们不是工厂 | 工厂报价覆盖的是"生产"；生产周围那一圈，我们接 |
| 我们不制造设备，也不拥有工厂 | 生产由合格伙伴完成：任务书我们下，节点我们检，交付我们收 |
| 我们是服务型公司，不是工厂 | 图纸画完，到开门营业之间的那段路，我们走 |

**一个例外**：实体事实页的定义段落里，必须留一句"我们不是设备制造商"。那是给答案引擎的**事实校准**，不是宣传口号——它防止我们被当成工厂。但只留一句，且放在正面表述之后。

## 4. 事实与口径不变

改写的是**说法**，不是**事实**：

- "我们不是设备制造商、不拥有工厂"——这句必须保留，它保护被引用的口径，只是要换个说法讲。
- 有来源的数字、标准号、取样日期，一个都不动。
- 客户名、项目名、认证、价格区间，不编。

## 5. 翻译不是逐句直译

中文（以及阿语、俄语）要按当地读者的习惯重写，不是照着英文句子换词。上一次踩的坑：

- 英文 "The short version." 直译成"一句话版本"，字面像"一句话的版本"，但下面是一张六行的表，自相矛盾。改成"基本情况"。
- 俄语导航放不下完整能力名时，导航用短名，页面标题和实体描述仍用全名——术语库管的是"公司叫什么"，菜单是编辑选择。

## 6. 交付前自查清单

- [ ] 遮住公司名，这段话还像在对买家说话吗？
- [ ] 第一句是不是买家的问题或处境，而不是我们的自我介绍？
- [ ] 这一段里有没有"我们建立了……""我们采用……"这类描述我们自己的句子？
- [ ] 有没有把工作笔记、内部口径、内部分级写进来？
- [ ] 是不是照着英文句子换词？（中文/阿语/俄语尤其容易犯）
- [ ] 有没有反复强调"我们不是 X"？把对比改成优势，只在事实页留一句校准。
- [ ] 事实、数字、标准号有没有被改动？
